EG79 APK Cloud Build (phone only)
1. On your phone open https://github.com/ and sign in/create a free account.
2. Create a new repository named eg79-android. Private is recommended.
3. Upload all files and folders in this ZIP to the repository root. Include .github/workflows/build-apk.yml.
4. Commit to main. The workflow should start automatically. Otherwise open Actions > Build EG79 APK > Run workflow.
5. Open the completed run and download the EG79-debug-apk artifact.
6. Extract the artifact ZIP and install app-debug.apk.
This is a debug APK for personal testing, not a Play Store release.
